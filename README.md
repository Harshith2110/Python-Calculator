# Python Calculator

A simple calculator built using Python.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Continuous calculations using a loop
- Exit option (y/n)

## How to Run

1. Install Python 3
2. Download `calculator.py`
3. Open Terminal or Command Prompt
4. Run:

```bash
python calculator.py
```

## Example

```text
Enter first number: 10
Enter operator (+, -, *, /): *
Enter second number: 5

Result = 50.0
```
