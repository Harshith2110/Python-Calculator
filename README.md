# Python Calculator

A simple command-line calculator built using Python.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Floor Division (//)
- Modulus (%)
- Power (**)
- Continuous calculations using a loop
- User-friendly interface

## Operators Supported

| Operator | Operation |
|----------|-----------|
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| // | Floor Division |
| % | Modulus (Remainder) |
| ** | Power (Exponent) |

## Technologies Used

- Python 3

## How to Run

```bash
python calculator.py
```

## Sample Output

```text

Enter first number: 10
Enter operator (+, -, *, /, //, %, **): **
```
